# remi-gateway

API Gateway de Remi Recetas: punto de entrada a los microservicios.

## Tecnologías

- NestJS
- TypeScript
- RabbitMQ / microservicios
- Jest
- Docker

## Estructura

```
📄 Dockerfile
📄 README.md
📄 eslint.config.mjs
📄 nest-cli.json
📄 package-lock.json
📄 package.json
📁 src
📁 test
📄 tsconfig.build.json
📄 tsconfig.json
```

## Cómo ejecutarlo

```bash
npm install
npm run start:dev
npm start
npm run build
npm run test
```
